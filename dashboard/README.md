# dashboard

Visualizaciones. Plan A: herramienta de BI. Plan B: `matplotlib` exportando PNG a esta carpeta.

Las seis que cuentan la historia:

1. **Curva de fatiga** — enganche y baja por número de exposición. De dónde sale el cap.
2. **Momento** — enganche por estado de señal. El 98.5 % contra el 1.5 %.
3. **Clic contra conversión, por producto** — el primero en clics es el último en eficiencia.
4. **Los dos rankings** — salud y rentabilidad, lado a lado. El orden se invierte.
5. **Simulación de políticas** — volumen, ingreso retenido y días en negativo.
6. **Embudo** — M1 a M5, statu quo contra política final.

La 3 es la que menos se espera y más se recuerda.
